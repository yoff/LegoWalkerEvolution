If the dashboard will not open

A local Python HTTP server must be running on this computer. If the browser says it cannot connect to 127.0.0.1:8788, start that server:

Follow the setup instructions, then from the repository directory:

.venv/bin/python -m legowalkers_sim.seeds --output output/recommended-seeds
sh scripts/dashboard.sh --dotnet "$(command -v dotnet)" --ldraw-library "$LDRAW_LIBRARY"

Wait for Live dashboard: http://127.0.0.1:8788/, then use the link above. The command works from any directory when given the full path to the script. It uses the project's existing Python environment.

What runs, and what does not

  • The command serves the stable experiment and prepares any needed implementation update.
  • It preserves previous results and unused trial allowance. It does not authorize or run simulations.
  • Simulation and animation workers start only through their separate dashboard buttons.
  • This command configures two independent screening/preflight processes and up to four simulation processes. Each passing realization can proceed without waiting for its siblings; screening and ready work are bounded to four candidates and the remaining trial allowance.
  • Blender is needed only for rendering new animations, not for viewing existing results.
  • Use Ctrl+C in the server terminal, or terminate the VS Code task, to stop the dashboard. Independently started workers are not stopped by this.

If startup reports a missing environment or another error, inspect the terminal and follow the project setup instructions. If the dashboard already opens, another server is running; do not start a duplicate.

A stopped server cannot deliver a custom HTTP error page. The browser's connection-error page cannot be replaced by this file without another always-running server or browser-specific software. This offline page is the recovery entry point, not a live server-status check.
